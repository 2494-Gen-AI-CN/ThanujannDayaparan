# Pokémon Higher or Lower

A Pokemon version of the Higher or Lower game using Gen 1 Pokémon. Instead of searches, it compares base stat totals (HP, attack, defense, etc. added together).

## How to play

- The left Pokémon shows its base stat total.
- The right Pokémon's total is hidden.
- Click **Higher** or **Lower** to guess how the right one compares to the left.
- If you're right, the right Pokémon becomes the new reference and you keep going. If you're wrong, the game ends.
