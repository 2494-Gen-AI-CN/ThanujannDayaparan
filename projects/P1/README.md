# Crop Disease Classification

## Problem Statement

Crop diseases can significantly impact agricultural productivity and crop yields. Early identification of plant diseases is important because it allows farmers to take action before infections spread and cause further damage.

This project aims to develop an image classification model using leaf images to identify whether potato and tomato plants are healthy or affected by common diseases. The model will classify images into six categories: healthy, early blight, and late blight for both crops.

The goal is to explore how deep learning and convolutional neural networks (CNNs) can be used to support early crop disease identification through image analysis.
